# 德尔斐战斗系统设计草案 v0.1

> 娱乐为主，反作弊优先，数值诚实。
> 核心理念：**今日的真实行动决定战力，而非历史属性堆叠。**

---

## 一、核心设计原则

### 反作弊机制
- **禁止直接用 character_stats.json 的属性数值作为战力基础**
  → 防止人为修改 JSON 作弊
- **战力 = 今日行动分（70%）+ 历史基础分（30%）**
  - 今日行动分：从当日 session jsonl 实时计算，无法预先篡改
  - 历史基础分：来自 character_stats.json，但权重压低

### 娱乐性优先
- 胜负有随机因子（±15%），强者也可能翻车
- 战报叙事比数字更重要——用具体的今日行动来描述「战斗过程」
- 失败也有收获（「虽败犹荣」称号线索）

---

## 二、今日战力计算维度（PvP / PvE 通用）

从当日 session jsonl 提取，实时计算：

| 维度 | 说明 | 权重 |
|------|------|------|
| **创造性深度** | 今天是否有开创性想法、设计新系统、提出新框架 | 25% |
| **认知突破** | 交互中是否修正了认知盲区、对已有观念有重新理解 | 20% |
| **执行密度** | 今天实际完成了多少具体产出（代码/文档/部署/分析） | 20% |
| **交互深度** | 问题的复杂度、对话的层次、是否追问到底层逻辑 | 15% |
| **成长显著度** | 今日 exp 增长 / 是否完成每日任务 / 是否解锁称号 | 20% |

历史基础分（30%）= level × 10 + 核心属性均值

## 三、个性化技能系统

### 技能生成原则
- **不使用预设技能库**
- 根据职业定位 + 今日高频关键词 + 当前称号，实时生成 2-3 个专属技能
- 技能分：物理系（执行/交付型行为）和 魔法系（思维/创意型行为）

### 技能示例（根据今日交互生成）

**物理系**（对应今日执行产出）：
- 「Cron 部署斩」：今天配置了自动化任务，造成持续伤害
- 「简历重构击」：今天完成了一次高质量文档输出，造成范围伤害

**魔法系**（对应今日思维产出）：
- 「洞察提炼术」：今天提炼出反直觉洞察，造成「认知震慑」效果（对手下回合行动减弱）
- 「PE 框架咒」：今天对 Prompt 体系有创新设计，造成「结构性压制」

**称号加成技能**（持有特定称号才能使用）：
- 持有「精密体系建筑师」→ 解锁「架构降维打击」
- 持有「规则锻造者」→ 解锁「边界锁定」（减少对手随机爆发）

## 四、PvP 模式

### 触发方式
- 用户说「我要 PK」「找人单挑」，或 Alice 在晚间发现两人今日都有高活跃度时主动提议

### 对战双方
- 双方当日战力独立计算
- 战力差距超过 40% 时，弱势方获得「以弱胜强」加成（随机暴击概率 +30%）

### 战报结构
```
⚔️ PvP 战报 — {date}
{玩家A} vs {玩家B}

【今日战力对比】
{A}: {战力值}  |  {B}: {战力值}

【技能释放】
{A} 使用「{技能名}」——{今日具体行动描述}，造成 {伤害} 点创意冲击！
{B} 使用「{技能名}」——{今日具体行动描述}，造成 {伤害} 点执行碾压！
...

【战局转折】
{随机事件，如「认知盲区修正」触发暴击}

【结果】
🏆 {胜者} 今日胜出！
「{今日最具决定性的行动}」是制胜关键。

【战后奖励】
胜者：+50 EXP · 解锁战斗称号线索
败者：+20 EXP「虽败犹荣」· 明日复仇加成 +10%
```

## 五、PvE 模式 — 小粉猪 Boss

### Boss 设定：小粉猪（Piglet.exe）

**人设**：
- 外表：萌萌的小粉猪 🐷，实际上是被 AI 过度喂养后进化的「低效思维具象体」
- 核心能力：用「差不多就行」「先这样吧」「以后再说」消耗玩家战力
- 弱点：遇到「具体行动记录」和「洞察提炼」会受到双倍伤害

**Boss 属性（每日随机波动）**：
- 基础 HP：300
- 今日强度 = 玩家今日未完成的任务数 × 50 + 随机值（±30）
  → 越懈怠，Boss 越强；越努力，Boss 越弱
- 特殊机制：若玩家今日无任何产出，Boss 直接满血且获得「拖延增幅」buff

**Boss 技能池**：
- 「拖延漩涡」：扣除玩家行动分 10%
- 「差不多就行」：随机取消玩家一个技能效果
- 「明日再说」：使玩家下一回合伤害减半
- 「舒适区护盾」：若玩家今日无创新行动，Boss 获得护盾

**Boss 弱点**：
- 玩家今日完成每日任务 → Boss 受到「体系冲击」，HP -80
- 玩家今日解锁新称号 → Boss 受到「身份进化震慑」，行动减弱一回合
- 玩家今日有认知盲区修正记录 → Boss 受到「顿悟之光」，双倍伤害

**战报叙事风格**：
```
🐷 PvE 战报 — {date}

小粉猪今日战力：{值}（因为你有 {N} 个未完成任务，它今天很精神）

【回合1】
你使用「{技能}」——{今日具体行动}
小粉猪受到 {伤害} 点「执行碾压」！（剩余 HP: {值}）
小粉猪反击「差不多就行」——你的创造性深度分暂时降低 10%

【回合2】
...

【结果】
{胜利} 你以 {今日制胜行动} 击败了小粉猪！
小粉猪临死前说：「我...明天...还会回来的...」🐷💨
+{EXP} EXP · 掉落道具：「{根据今日行动生成的道具名}」

或

{失败} 小粉猪今天赢了，但它也只敢赢你一天。
明日复仇加成 +15%。今天，先好好休息。
```

## 八、道具系统详细设计（思维碰撞型）

### 设计理念
> 道具不是数值加成，而是「对方世界的一扇窗」。
> 捡到对手掉落的道具 = 被迫接触一个你原本不会主动涉足的领域。

### 道具生成逻辑
战斗结束后，胜者获得对方今日交互记录中最核心的1个领域作为道具：

```python
# 伪代码
loser_top_topic = 分析对方今日session的主题分布，取最高频且与胜者领域最不同的topic
道具名 = f"「{loser_top_topic}领域」思维碎片"
道具效果 = f"明天与 {loser_top_topic} 相关的任务 EXP +50%，且今日任务面板会增加一条跨域挑战"
```

### 道具示例

**胜者擅长 AI 工程，对手擅长金融投资**：
> 掉落：「止损纪律」思维碎片
> 效果：明日任务面板新增跨域任务——「用 AI 工程的系统化思维，为你的投资体系设计一个自动化止损规则」
> EXP 奖励：完成跨域任务 +300（高于普通任务的 +200）

**胜者擅长文字写作，对手擅长 Prompt 工程**：
> 掉落：「PE 框架」思维碎片  
> 效果：明日任务面板新增——「用你的文学叙事能力，重写一个 PE 的任务描述，让它更有感染力」

### 跨域任务奖励放大原因
跨域任务比日常任务 EXP 多 50%，因为：
- 打破惯性思维成本更高
- 跨域碰撞是认知升级最快的路径
- 强迫接触陌生领域 = 德尔斐「认识你自己」的核心

## 九、社区联动对战（未来版本）

### 数值卡片发布
战斗结束后生成「战斗卡片」（HTML 或图片），可分享到小红书/朋友圈：
```
┌─────────────────────────┐
│ ⚔️ 德尔斐战士            │
│ {职业名} · Lv.{level}    │
│                         │
│ 今日战力：{值}           │
│ 技能：{技能1} / {技能2}  │
│ 今日成就：{最大亮点}     │
│                         │
│ 扫码挑战 →  [QR]        │
└─────────────────────────┘
```

### 跨用户 PvP 流程
1. A 发布战斗卡片
2. B 扫码/点击，系统读取 B 的今日 character_stats.json
3. 双方今日行动分独立计算
4. 生成对战战报，双方均收到
5. 道具根据对方实际交互领域实时生成（非模板）
