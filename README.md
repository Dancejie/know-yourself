「认识你自己」— γνῶθι σεαυτόν
源自古希腊德尔斐神庙的神谕铭文，经苏格拉底发展为自省方法论，并在柏拉图的哲学体系中升华为对人类心智结构的系统性探索。柏拉图将灵魂分为三个维度：Logos（理性）、Thumos（激情）、Epithumia（欲望）——这三者的比例关系，决定了一个人的认知风格、决策模式与行动倾向。
德尔斐计划，是这一古老命题的现代实践。
零、一个被颠倒的权力结构
每天，你使用各种互联网产品——刷信息流、搜索、购物、社交。
在这个过程中，平台在悄悄地做一件事：用你的数据，分析你。
你的点击轨迹、停留时长、搜索关键词、购买记录……这些行为数据，被平台用来构建精密的用户画像模型。算法知道你什么时候情绪低落、什么类型的内容让你停下来、什么样的价格会让你冲动下单。它用这些认知，向你推送能让你继续停留的内容，构建只属于你的注意力茧房——让你看到的世界，越来越像你已经相信的那个世界。
Company对你了如指掌。你对自己，却未必。
这是一个被颠倒的权力结构：你的数据在为别人服务，帮助平台更好地影响你、留住你、向你变现。而你自己，从未真正系统地看清过自己的行为模式、认知偏好和思维盲区。
德尔斐计划想做的，是把这个权力翻转过来。
不是把你的数据交出去，而是让你自己看见它。不是被算法画像，而是主动读懂自己。
认识自己，才能真正掌控自己的注意力、决策和成长路径。
一、这是什么
德尔斐计划（Project Delphoi） 是一个运行在 Lobi（Lobi） 上的行为智能分析 Skill。
它做一件简单但罕见的事：读你说过的话，还原你是谁。
系统会分析你与 AI 助手的全量历史对话——你问了什么、怎么问的、问题背后的结构、关注的领域、活跃的时段、高频出现的关键词——通过数据驱动的推理，生成一份属于你的行为智能档案。
不是问卷。不是自我报告。是从你真实的数字行为里读出来的你。



二、为什么要做这件事
2.1 主动认识自我：优势可以放大，盲区可以修正

大多数人对自己的认知，停留在模糊的自我感觉里。我们知道自己"比较理性"，却不知道理性到什么程度；知道自己"执行力一般"，却没有量化过这个"一般"在哪个维度上出现了断层。
德尔斐计划给你的，是数据上的自我镜像：
优势：哪些能力维度真正高于平均？这些维度的组合，构成你独特的竞争力截面
认知盲区：哪些模式在你的行为数据里反复出现，但你可能从未意识到？
灵魂三分雷达：你的 Logos/Thumos/Epithumia 比例，揭示你在决策时最依赖的心智模式
看见，是改变的前提。



2.2 优化 AI 交互逻辑：让助理真正因材施助
「因材施教」是孔子的教育哲学——同一个问题，对不同学生应当给出不同深度、不同角度的引导。
德尔斐计划的第二个目标，是把这个逻辑应用到 AI 交互上：

3.2 推理框架：柏拉图灵魂三分
所有分析结果，最终收敛到柏拉图的三维框架上：
Logos（理性）   ████████████████████ 75%   → 思维质感：精密 / 析理 / 结构 / 直觉
Thumos（激情）  ████░░░░░░░░░░░░░░░░ 18%   → 行动质感：驱动 / 笃行 / 沉思
Epithumia（欲望）██░░░░░░░░░░░░░░░░░░  7%   → 欲望质感：探索 / 体验 / 享乐
三维比例决定你的专属原型代号——不是测评量表里的标准类型，而是从你的数据里生成的专属称谓：
Precision Architect · 精密体系建筑师
这个代号由两个维度组合生成：修饰词（由 Logos 比例决定） × 职位词（由主导维度 + 最强能力共同决定）。每个人读到的，都应该是属于自己的名字，而不是"你命中了第几类"。
3.3 数据驱动，结论有据
系统的每一条分析结论，都标注数据来源与置信度等级：
High：直接从行为数据观测到的模式
Medium：基于统计规律的推断
Low：间接推导，建议交叉验证
禁止无据猜测。不确定时标注「待验证」。

六、设计原则
① 数据先行，结论靠后
所有推断必须有数据支撑，置信度透明，无据不猜。
② 专属性优于分类性
每个人的原型代号是从他的数据里生成的，不是预设类别的映射。分布自然均匀，领袖/统帅类称谓只在数据真正支持时才出现。
③ 看见，而不是贴标签
档案的目的是让人读完感到"被看见"——有一种被精准还原的认知感，而不是被归入某个心理学类型。
④ 传播设计
HTML 密档的视觉设计和交互逻辑，专门为可传播性优化：涂黑解密的好奇心驱动、倒计时销毁的稀缺感、原型印章的仪式感。读完想分享，是设计目标之一。
「认识你自己」——这句话刻在德尔斐神庙的门楣上，不是为了让人回答，而是为了让人持续追问。
档案不是终点，是起点。
